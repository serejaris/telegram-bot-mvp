# Экспорт истории чата за диапазон дат

**Дата:** 2025-12-09
**Статус:** Утверждён

## Обзор

Расширение таба "Экспорт" — добавление выбора периода (пресеты + произвольный диапазон) вместо одной даты. Результат: один JSON-файл со всеми сообщениями за период.

## UI

```
[ экспорт ]

┌─────────────────────────────────────────────────┐
│  период:                                        │
│  [неделя] [месяц] [диапазон]                    │
│                                                 │
│  ┌─ при выборе "диапазон" ─────────────────┐   │
│  │  от: [2025-12-02]  до: [2025-12-09]     │   │
│  └─────────────────────────────────────────┘   │
│                                                 │
│  [скачать JSON]                                 │
│                                                 │
│  * экспорт за полный период · UTC+3 (Москва)   │
└─────────────────────────────────────────────────┘
```

**Логика пресетов:**
- Неделя = последние 7 дней (вчера − 6 дней назад)
- Месяц = последние 30 дней (вчера − 29 дней назад)
- Диапазон = два date picker'а (от/до)

## API

**Новый эндпоинт:**
```
GET /api/chats/{chat_id}/messages/export?from=YYYY-MM-DD&to=YYYY-MM-DD
```

**Параметры:**
- `from` (обязательный) — начало периода
- `to` (обязательный) — конец периода (включительно)

**Ответ:**
```json
{
  "chat_id": -100123456,
  "chat_title": "Название чата",
  "period": {
    "from": "2025-12-02",
    "to": "2025-12-09"
  },
  "messages_count": 847,
  "messages": [
    {
      "id": 12345,
      "date": "2025-12-02T10:30:00",
      "user": {"id": 123, "name": "Иван"},
      "text": "...",
      "type": "text"
    }
  ]
}
```

**Обработка ошибок:**

| Ситуация | Ответ |
|----------|-------|
| `from` > `to` | 400: "Неверный диапазон дат" |
| Нет сообщений | 200: пустой массив messages |
| Чат не найден | 404 |

**Ограничения:** нет лимита по количеству сообщений.

## Что НЕ входит

- Другие форматы (CSV, TXT)
- Прогресс-бар загрузки
- Кэширование экспортов
- Экспорт нескольких чатов
